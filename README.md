# Project Title
    Customer segmentation for personalized content and markating optmization for Netflix

# Business Problem
     Netflix is exprencing inconsistant user engagement across its subscriber base.
     While some users binge watch content daily, other log in ocassionally or
     Only consumer specific type for content(e.g kids show, movies or limited series)
     Currently, all the users are receiving same recommendation, marketing messages,
     Offer regardless of their viewing behaviour.

     The buisness wants to understand how different types of customers use the platform,
     so that it can personalized content suggestions, improve retention and optimise investment in new content.

# Business Objactive
     Build a data-driven customer segmentation model using Unsupervised (K-Means)
     To identify diffrent cluster or group based on their viewing pattern, Plan type, device usage and ratings Etc.
     
# Dataset
    We have a dataset with 200 records and 9 columns, Where we have a informations like customers Monthly Watch Hours,
    Movies Per Month, Percentage of Kids Content, Ratings, age etc.

    9. PCA Visualization Plot
